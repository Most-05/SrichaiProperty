# 📚 Srichai Property Documentation

เอกสารและไฟล์ข้อมูลประกอบโปรเจกต์ Srichai Property

## สารบัญโฟลเดอร์

- **`manuals/`**: คู่มือการใช้งานระบบสำหรับแต่ละบทบาท (Role)
  - `agent-guide.md`: คู่มือนายหน้า (Agent Portal)
  - `customer-guide.md`: คู่มือลูกค้า (Customer Portal)
  - `admin-guide.md`: คู่มือแอดมิน (Admin Portal)
- **`database_schema.md`: เอกสารโครงสร้างตารางฐานข้อมูลและความสัมพันธ์ (ER Diagram & Table Specs)
- **`implementation_plan.md`: เอกสารแผนงานและการพัฒนาฟีเจอร์ของระบบ
- **`G14_Proposal.docx`: เอกสารข้อเสนอโครงงานฉบับสมบูรณ์
- **`database_backup.sql`: สคริปต์ SQL สำหรับสำรองหรือสร้างโครงสร้างฐานข้อมูลเริ่มต้น
